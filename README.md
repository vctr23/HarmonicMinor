## Introduction
HarmonicMinor is a Kotlin-based project which consists of a Musical instruments based android app shop. This app is designed to provide music enthusiasts and musicians with a seamless and intuitive platform to browse, compare, and purchase[joke ;)] a wide range of musical instruments from various brands.

## Features
- **User Authentication**: Uses firebase to authenticate users and firestore DB.
- **Image Loading**: Uses COIL to load images from outside links.
- **Navigation**: Uses navigation components to navigate between screens.
- **MVVM Architecture**: Uses a very basic MVVM architecture (only on some screens).

## Installation
To install HarmonicMinor, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/vctr23/HarmonicMinor.git
   ```
2. Navigate to the project directory:
   ```bash
   cd HarmonicMinor
   ```
3. Open the project in Android Studio.


## Usage
To use HarmonicMinor, follow these steps:

1. Open the project in Android Studio.
2. Create a new Virtual Device or connect your own Android smartphone.
3. Run the project on the Virtual Device.
4. - If you are using your own smartphone, make sure to enable USB debugging.
- Settings > About phone > Tap Build version number a couple of times > Developer options > Enable USB debugging.

### Technologies Used
This project leverages the following technologies:
- **Kotlin**: The primary programming language for developing the app.
- **Firebase**: For user authentication and database management.
- **COIL**: For efficient image loading and caching.
- **Navigation Components**: For seamless navigation between screens.
- **MVVM Architecture**: To ensure a clean and maintainable code structure.
